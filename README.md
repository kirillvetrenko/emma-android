# Emma English — Android

Это исходный Android-проект. Готового APK в архиве нет: в среде подготовки отсутствует Android SDK и недоступны серверы зависимостей.

84 открытых урока, 420 заданий, XP и локальный прогресс, ссылки TED/YouTube, заметки, озвучка Android с выбором установленных голосов и темпа, системное распознавание речи Android, автоматический микрофон после образца. Нет оплаты или блокировки уроков по порядку.

Речь требует разрешения микрофона и совместимой службы распознавания на устройстве. Сеть может требоваться службе речи и сетевым голосам. Видео требуют интернет. AI-чат из HTML по-прежнему требует среды Claude: собственного AI-сервера нет. Автоматического получения расшифровок видео нет. Проверяется распознанный текст, а не качество произношения.

## Получить APK через GitHub

1. Загрузите содержимое этой папки в корень репозитория. Сохраните скрытую папку `.github/workflows/`.
2. Откройте Actions → Build Emma APK → Run workflow. Push файлов также запускает сборку.
3. После успешного выполнения скачайте артефакт Emma-Android-APK. Распакуйте и установите app-debug.apk на Android 8.0 или новее.

Это тестовая debug-подпись. При пересборке на другом runner ключ может измениться: тогда потребуется переустановка с потерей локального прогресса. Для стабильных обновлений настройте собственный постоянный ключ подписи; секреты не коммитьте.

## Локальная сборка

Откройте проект в Android Studio. Нужны JDK 17, SDK 35 и Gradle 8.9. Команда: `gradle :app:assembleDebug`. Результат: `app/build/outputs/apk/debug/app-debug.apk`.

## Проверка

Проверены синтаксис JavaScript, протокол Android/JS, XML manifest и состав архива. Компиляция Android и работа на телефоне не проверены.
