# Emma 2.0 — английский без спешки

84 темы A1–B1 в 12 модулях. Каждая тема состоит из объяснения, первой практики и второй практики: всего 252 открытых урока и 1008 заданий.

## Что изменилось

- Русские объяснения, схемы и по три примера с переводом у каждой темы.
- Две разные практики: перевод, пропуски, плитки, аудирование, диктант и речь.
- Отдельное повторение ошибок; XP начисляется один раз за урок.
- Простой интерфейс: курс, повторение, видео, настройки. Поиск и фильтр уровня.
- Нативное распознавание Android, выбор установленных голосов и темпа. Задания с аудио можно пропускать без блокировки урока.
- Экспорт и импорт прогресса в JSON через системный выбор файла Android.
- Старые оценки `et3` переносятся в первую практику соответствующих тем.

Рабочего бесплатного облачного AI-подключения у проекта нет. Поэтому чат, зависимость от Claude, настройки AI, разбор видео через AI и серверные заготовки удалены. Видеотека TED/YouTube с самостоятельными заметками сохранена; приложение не получает содержание видео по ссылке и не оценивает пересказ.

## Возможности и ограничения

Уроки и текстовые задания работают офлайн. Голоса и распознавание зависят от служб Android и могут требовать интернет; нужен доступ к микрофону. Видео требуют сеть. Сравнивается распознанный текст, а не качество произношения.

Прогресс хранится на устройстве. Перед переустановкой сохраните резервную копию. Тестовый APK имеет debug-подпись, которая может отличаться от старой сборки: тогда установка поверх неё невозможна и потребуется переустановка с потерей данных, если они не сохранены отдельно. Для выпуска нужен постоянный собственный ключ подписи, хранящийся вне репозитория.

## APK

GitHub Actions → Build Emma APK → артефакт Emma-Android-APK → app-debug.apk. Android 8.0+.

Локально: JDK 17, Gradle 8.9, SDK 35; `gradle :app:assembleDebug`.

## Исходники и проверки

`app/src/main/assets/index.html` — автономный интерфейс с учебными материалами; `android-speech.js` — адаптер Android. `web/` содержит исходники интерфейса и проверки. `node web/tests/course.cjs` проверяет все задания, доступность уроков, XP, повторение ошибок, миграцию и восстановление данных, безопасные ссылки и голосовые сценарии с заглушками. Проверки не заменяют тестирование на реальном устройстве.
